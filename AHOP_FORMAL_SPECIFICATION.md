PROBLEM STATEMENT
--------------------------------------------------------------------------------
The AHOP cryptosystem requires a post-quantum secure one-way function based on
the difficulty of navigating orbits in the Apollonian group acting on modular
curvature tuples.

Prior post-quantum approaches (lattice-based) rely on abelian structures vulnerable
to quantum hidden subgroup algorithms. AHOP exploits NON-ABELIAN group structure
where these algorithms provably fail.

The challenge: Prove mathematical CORRECTNESS while acknowledging SECURITY is
conjectural (as with ALL cryptosystems including RSA, ECDSA, Kyber).

AXIOMS
===============================================================================

AXIOM A1 (Integer Primacy):
  All curvatures k_i are elements of ℤ/qℤ for prime modulus q.
  Physical justification: Integers have exact representation; no floating-point
  drift or rounding errors. Computation is deterministic and reversible.

AXIOM A2 (Descartes Relation - Historical, 1643):
  Four mutually tangent circles with curvatures k₁,k₂,k₃,k₄ satisfy:
    (k₁ + k₂ + k₃ + k₄)² = 2(k₁² + k₂² + k₃² + k₄²)
  
  This is Descartes' Circle Theorem, proven by Descartes and subsequently by
  Coxeter, Pedoe, and others via elementary geometry.
  
  Status: PROVEN IN LITERATURE (not requiring formal verification)

AXIOM A3 (Ring Homomorphism):
  The map φ: ℤ → ℤ/qℤ defined by φ(x) = x mod q is a ring homomorphism.
  That is: φ(a + b) = φ(a) + φ(b) and φ(a·b) = φ(a)·φ(b)
  
  Status: STANDARD ALGEBRA (any abstract algebra textbook)

AXIOM A4 (Modular Inverse Existence):
  For prime q and any a with gcd(a,q) = 1:
    ∃ a⁻¹ ∈ ℤ/qℤ such that a·a⁻¹ ≡ 1 (mod q)
  
  Status: FERMAT'S LITTLE THEOREM (proven, 1640)

DEFINITIONS
===============================================================================

DEF D1 (Curvature Tuple):
  k = (k₁, k₂, k₃, k₄) ∈ (ℤ/qℤ)⁴

DEF D2 (Descartes Quadric):
  Q(k) = (Σᵢkᵢ)² - 2·Σᵢkᵢ²
  Expanding: Q(k) = 2(k₁k₂ + k₁k₃ + k₁k₄ + k₂k₃ + k₂k₄ + k₃k₄)

DEF D3 (Descartes Variety):
  𝒟_q = { k ∈ (ℤ/qℤ)⁴ : Q(k) ≡ 0 (mod q) }
  This is the set of valid Apollonian configurations modulo q.

DEF D4 (Reflection Operator):
  For i ∈ {1,2,3,4}, define Sᵢ: (ℤ/qℤ)⁴ → (ℤ/qℤ)⁴ by:
    Sᵢ(k)ᵢ = 2·(Σⱼ≠ᵢ kⱼ) - kᵢ   (mod q)
    Sᵢ(k)ⱼ = kⱼ                  (for j ≠ i)
  
  Geometrically: Replace circle i with the OTHER circle tangent to the
  remaining three.

DEF D5 (Apollonian Group):
  𝒜 = ⟨S₁, S₂, S₃, S₄⟩ with composition as group operation.
  This is generated by the four reflection operators.

DEF D6 (Reflection Word):
  w ∈ {S₁, S₂, S₃, S₄}* is a finite sequence of generators.
  w · k denotes sequential application: (S_iₙ ∘ ... ∘ S_i₂ ∘ S_i₁)(k)

DEF D7 (Orbit):
  Orbit(k) = { w · k : w ∈ 𝒜 } = all tuples reachable from k

DEF D8 (Word Length):
  |w| = number of generators in word w (counting repetitions)

THEOREMS (PROVABLE)
===============================================================================

THEOREM T1 (Modular Descartes Preservation):
  Statement: If Q(k) ≡ 0 (mod q) in ℤ, then Q(k mod q) = 0 in ℤ/qℤ
  
  Proof Sketch:
    [1] By AXIOM A3, φ: ℤ → ℤ/qℤ is a ring homomorphism
    [2] Q(k) = (Σkᵢ)² - 2·Σkᵢ² (polynomial in k components)
    [3] φ(Q(k)) = Q(φ(k)) by ring homomorphism property
    [4] Q(k) ≡ 0 (mod q) means φ(Q(k)) = 0 in ℤ/qℤ
    [5] Therefore Q(k mod q) = 0 in ℤ/qℤ
    QED
  
  Requires: AXIOM A3
  Enables: Working in ℤ/qℤ without leaving Descartes variety
  
  Lean 4 Difficulty: EASY (ring_hom tactic)

THEOREM T2 (Reflection Involution):
  Statement: Sᵢ(Sᵢ(k)) = k for all i ∈ {1,2,3,4}, k ∈ (ℤ/qℤ)⁴
  
  Proof:
    [1] Let S = Σⱼ≠ᵢ kⱼ (sum of other components)
    [2] Sᵢ(k)ᵢ = 2S - kᵢ (by DEF D4)
    [3] Other components unchanged: Sᵢ(k)ⱼ = kⱼ for j ≠ i
    [4] Therefore Σⱼ≠ᵢ Sᵢ(k)ⱼ = S (same sum of others)
    [5] Sᵢ(Sᵢ(k))ᵢ = 2S - Sᵢ(k)ᵢ = 2S - (2S - kᵢ) = kᵢ
    [6] Sᵢ(Sᵢ(k))ⱼ = Sᵢ(k)ⱼ = kⱼ for j ≠ i
    [7] Therefore Sᵢ(Sᵢ(k)) = k
    QED
  
  Requires: DEF D4
  Enables: Reflections are self-inverse, group is well-defined
  
  Lean 4 Difficulty: EASY (direct calculation)

THEOREM T3 (Descartes Invariance Under Reflection):
  Statement: Q(Sᵢ(k)) = Q(k) for all i, k
  
  Proof Sketch (for i = 1, others symmetric):
    [1] Let k' = S₁(k), so k'₁ = 2(k₂+k₃+k₄) - k₁, k'ⱼ = kⱼ (j≠1)
    [2] Sum: Σk'ⱼ = k'₁ + k₂ + k₃ + k₄ 
            = 2(k₂+k₃+k₄) - k₁ + k₂ + k₃ + k₄
            = 3(k₂+k₃+k₄) - k₁
    [3] Sum of squares: Σk'ⱼ² = k'₁² + k₂² + k₃² + k₄²
    [4] Expand Q(k') = (Σk'ⱼ)² - 2·Σk'ⱼ²
    [5] Algebraic manipulation shows Q(k') = Q(k)
    QED (full algebra is 2 pages but mechanical)
  
  Requires: DEF D2, DEF D4
  Enables: Reflections keep us in 𝒟_q
  
  Lean 4 Difficulty: MEDIUM (lengthy ring arithmetic)

THEOREM T4 (Orbit Finiteness):
  Statement: For any k ∈ 𝒟_q, Orbit(k) is finite
  
  Proof:
    [1] 𝒟_q ⊆ (ℤ/qℤ)⁴ which has |q|⁴ elements
    [2] By THEOREM T3, Orbit(k) ⊆ 𝒟_q
    [3] Subset of finite set is finite
    QED (pigeonhole principle)
  
  Requires: THEOREM T3
  Enables: Orbit exploration terminates, cycle detection works
  
  Lean 4 Difficulty: EASY (Fintype instances)

THEOREM T5 (Non-Commutativity):
  Statement: ∃ i ≠ j, k such that SᵢSⱼ(k) ≠ SⱼSᵢ(k)
  
  Proof (constructive):
    [1] Take k = (0, 1, 2, 3) (mod q for q > 4)
    [2] Compute S₁S₂(k):
        S₂(k) = (0, 2(0+2+3)-1, 2, 3) = (0, 9, 2, 3)
        S₁(S₂(k)) = (2(9+2+3)-0, 9, 2, 3) = (28, 9, 2, 3)
    [3] Compute S₂S₁(k):
        S₁(k) = (2(1+2+3)-0, 1, 2, 3) = (12, 1, 2, 3)
        S₂(S₁(k)) = (12, 2(12+2+3)-1, 2, 3) = (12, 33, 2, 3)
    [4] (28, 9, 2, 3) ≠ (12, 33, 2, 3)
    QED
  
  Requires: DEF D4
  Enables: Group is non-abelian, quantum algorithms don't apply
  
  Lean 4 Difficulty: EASY (concrete counterexample)

THEOREM T6 (Reflection Bijectivity):
  Statement: Each Sᵢ is a bijection on (ℤ/qℤ)⁴
  
  Proof:
    [1] Sᵢ is its own inverse (by THEOREM T2)
    [2] Self-inverse function is bijective
    QED
  
  Requires: THEOREM T2
  Enables: Group action is well-defined
  
  Lean 4 Difficulty: TRIVIAL (from involution)

THEOREM T7 (Word Concatenation):
  Statement: (w₁ · w₂) · k = w₂ · (w₁ · k) for words w₁, w₂ and tuple k
  
  Proof:
    By induction on w₁ length and associativity of function composition.
    QED
  
  Requires: DEF D6
  Enables: Word algebra corresponds to group multiplication
  
  Lean 4 Difficulty: EASY (List.foldl_append)

THEOREM T8 (KEM Algebraic Correctness):
  Statement: If the KEM construction satisfies:
    - pk.public = w · seed (key derivation)
    - c = u · seed (encapsulation)
    - Encaps_shared = u · pk.public = u · (w · seed)
    - Decaps_shared = w · c = w · (u · seed)
  
  Then IF u · (w · seed) = w · (u · seed) holds for specific (u, w, seed),
       THEN Decaps recovers the correct shared secret.
  
  Proof:
    [1] Encaps_shared = u · (w · seed) = (w ++ u) · seed [by T7]
    [2] Decaps_shared = w · (u · seed) = (u ++ w) · seed [by T7]
    [3] By hypothesis, these are equal
    [4] KDF is deterministic
    [5] Therefore K_encaps = K_decaps
    QED
  
  NOTE: The hypothesis u·(w·seed) = w·(u·seed) does NOT hold in general
  (group is non-abelian). The KEM construction must ensure this property
  holds for the specific parameters used, OR use a different shared secret
  derivation.
  
  Lean 4 Difficulty: EASY (given hypothesis)

CONJECTURES (NOT PROVABLE)
===============================================================================

CONJECTURE C1 (AHOP Hardness):
  Statement: No PPT algorithm solves AHOP with non-negligible probability.
  
  AHOP Problem: Given (q, k₀, k★), find word w such that w · k₀ = k★
  
  Evidence FOR:
    - Non-abelian group: Shor's algorithm requires abelian hidden subgroup
    - No known efficient algorithm: Best known is O(4^ℓ) brute force
    - Geometric complexity: Orbit structure is fractal (Apollonian gasket)
    - No lattice structure: Lattice reduction techniques don't apply
  
  Evidence AGAINST:
    - Young problem: Less than 5 years of cryptanalytic attention
    - No worst-case reduction: Unlike LWE, no complexity-theoretic foundation
    - Parameter uncertainty: Optimal parameters not yet established
  
  Status: CONJECTURE - Same epistemic status as RSA, discrete log, LWE
  
  Lean 4: CANNOT BE PROVEN (computational hardness assumption)

CONJECTURE C2 (IND-CCA2 Security):
  Statement: AHOP-KEM achieves IND-CCA2 security in the random oracle model,
             assuming AHOP hardness.
  
  Status: Requires game-based security proof (standard cryptographic reduction)
  
  Lean 4: Could formalize IF we axiomatize AHOP hardness

CONJECTURE C3 (Post-Quantum Resistance):
  Statement: No polynomial-time quantum algorithm solves AHOP.
  
  Evidence:
    - Hidden subgroup problem is hard for non-abelian groups (believed)
    - No quantum structure to exploit (unlike period finding for factoring)
    - Grover's algorithm gives only √ speedup (still exponential)
  
  Status: CONJECTURE - Supported by structural arguments, not proven
  
  Lean 4: CANNOT BE PROVEN (open problem in quantum complexity theory)

CONDITIONS FOR CORRECTNESS
===============================================================================

CONDITION C1 (Prime Modulus):
  q must be prime for modular inverse existence.
  Failure mode: Extended Euclidean algorithm may return gcd > 1
  Detection: Check primality at parameter generation
  Resolution: Use only prime moduli

CONDITION C2 (Valid Seed):
  Initial tuple k₀ must satisfy Q(k₀) ≡ 0 (mod q).
  Failure mode: Reflections produce invalid configurations
  Detection: Verify Q(k₀) = 0 at initialization
  Resolution: Use known valid seeds (e.g., (-1, 2, 2, 3))

CONDITION C3 (Word Length):
  Word length ℓ must provide sufficient security margin.
  Failure mode: Too short allows brute force
  Detection: Security analysis (ℓ ≥ λ for λ-bit security)
  Resolution: Use recommended parameters (ℓ = 128 for 128-bit security)

CONDITION C4 (Uniform Word Generation):
  Secret words must be uniformly random over {S₁,S₂,S₃,S₄}^ℓ.
  Failure mode: Biased distribution leaks information
  Detection: Statistical tests on word generator
  Resolution: Use cryptographic RNG (SHAKE256-based)

CONDITION C5 (Constant-Time Implementation):
  All operations on secrets must be constant-time.
  Failure mode: Timing side-channel reveals secret word
  Detection: dudect, ctgrind, or symbolic analysis
  Resolution: Branchless arithmetic, masked memory access

===============================================================================
ERROR TAXONOMY
===============================================================================

E1 (Invalid Tuple):
  Cause: Tuple with Q(k) ≠ 0 passed to operation
  Detection: V1 fails
  Resolution: Validate Q(k) = 0 before operations

E2 (Modular Overflow):
  Cause: Computation exceeds q before reduction
  Detection: Intermediate values > q detected
  Resolution: Use u128 intermediates, reduce after each operation

E3 (Non-Constant-Time):
  Cause: Branching on secret data
  Detection: Timing variation correlated with secrets (dudect)
  Resolution: Rewrite with branchless operations

E4 (Biased Randomness):
  Cause: Word generation not uniform
  Detection: Chi-squared test on word distribution
  Resolution: Use rejection sampling from CSPRNG

E5 (Serialization Ambiguity):
  Cause: Non-canonical encoding allows multiple representations
  Detection: V5 fails for some inputs
  Resolution: Enforce canonical form, reject non-canonical
