# 08_TUTORIALS - Learning Resources

This folder contains all tutorials, learning materials, and demos for QMNF System.

## Contents

### beginner/
Getting started tutorials.
- Installation guide
- First rational operation
- Basic integer arithmetic

### intermediate/

- Neural network setup
- FHE basics
- FFI usage patterns

### advanced/
Expert-level content.
- Custom arithmetic types
- Performance optimization
- System extension

### demos/
Working demonstration applications.

```
beginner/ ─────► intermediate/ ─────► advanced/
    │                   │                  │
```

## Prerequisites

1. Python 3.9+ and Rust 1.70+
2. Basic understanding of integer arithmetic
3. Familiarity with command line
