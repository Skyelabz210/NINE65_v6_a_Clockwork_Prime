# 01_GUIDES - Master Documentation

This folder contains the four master guides for QMNF System, each targeting a specific audience.

## Contents

### SYSTEM_GUIDE/
Complete architecture understanding for anyone wanting to understand the full system.
- Architecture overview
- Component reference
- Integration patterns

### USER_GUIDE/
For end users who want to use QMNF in their projects.
- Getting started
- Tutorials
- Examples

### DEVELOPER_GUIDE/
For contributors who want to extend or modify QMNF.
- Coding standards
- API reference
- Integration guides

### RESEARCHER_GUIDE/
For academic and research use.
- Mathematical foundations
- Proofs
- Research papers

## Design Philosophy

These guides **reference** content from other daily_planet folders (02-12) rather than duplicating it. This keeps content DRY (Don't Repeat Yourself) and ensures consistency.
