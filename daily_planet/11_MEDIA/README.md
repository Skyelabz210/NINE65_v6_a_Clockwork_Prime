# 11_MEDIA - Non-Text Assets

This folder contains all non-text media assets for QMNF System documentation.

## Contents

### images/
General images.
- Logos
- Icons
- Illustrations

### diagrams/
Technical diagrams.
- Architecture diagrams
- Data flow diagrams
- UML diagrams

### screenshots/
Application screenshots.
- UI captures
- Output examples
- Demo screenshots

### videos/
Video content.
- Tutorials
- Demos
- Presentations

## Usage Guidelines

When referencing media in documentation:
```markdown
![Alt text](../11_MEDIA/images/filename.png)
```

## Naming Conventions

- Use descriptive names: `crt_architecture_diagram.png`
- Include date for snapshots: `dashboard_2025-12-16.png`
- Use lowercase with underscores

## Supported Formats

| Type | Formats |
|------|---------|
| Images | PNG, JPG, SVG, GIF |
| Diagrams | PNG, SVG, PDF |
| Videos | MP4, WebM |
