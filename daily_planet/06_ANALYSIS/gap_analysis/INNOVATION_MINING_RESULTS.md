└─ Maturity: Validated

**ABILITIES**
├─ Primary: Ranks applications by expected return on investment
├─ Novel: Combines performance gains, market size, barriers, and fit into single score
└─ Synergy: Integrates with benchmark data for performance_score component

**MATHEMATICS**
├─ Foundation: Multi-criteria decision analysis
├─ Key Formula: ROI = (perf_gain × usage_freq × market × fit × barrier) / impl_cost
├─ Normalization: log-scale for market size, linear for fit scores
└─ Proof Status: Empirical (sensitivity analysis needed)

**COMPONENT BREAKDOWN**
```
ROI Score = (Performance_Score × Market_Score × Fit_Score × Barrier_Score) / Cost_Score

Where:
- Performance_Score = log10(speedup + 1) × log10(usage_frequency + 1) / 20
- Market_Score = log10(market_value + 1) / 12
- Fit_Score = innovation_fit × competitive_advantage
- Barrier_Score = 1 - (adoption_barrier + regulatory_complexity) / 2
- Cost_Score = log10(implementation_hours × hourly_rate + 1) / 6
```
