## Key Procedures Quick Links

### Pre-Merge Checklist
**From:** MERGE_CONFLICT_RESOLUTION_REPORT.md → Best Practices for Future Merges
1. Ensure working tree is clean
2. Update to latest main/master
3. Review changes in feature branch
4. Identify potential conflict areas
5. Back up current state

### Conflict Resolution Guidelines
**From:** MERGE_CONFLICT_RESOLUTION_REPORT.md → Best Practices → Guidelines
1. Assess conflict type (structural, code, documentation)
2. Review resolution strategy matrix
3. Implement appropriate resolution
4. Test after resolution
5. Document decisions

### Post-Merge Testing
**From:** MERGE_CONFLICT_RESOLUTION_REPORT.md → Best Practices → Testing Requirements
```bash

# Rust code
cargo build --release           # Must compile
cargo test                       # All tests pass
cargo clippy --all-targets      # No warnings

# Python code
pytest tests/ -v                 # All tests pass
make quality-check              # Linting passes
mypy qmnf                        # Type checking passes
```
