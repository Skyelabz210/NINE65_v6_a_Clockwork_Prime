# QMNF Benchmark Results

This directory contains consolidated benchmark results from all QMNF components.

## Structure

Each benchmark run creates a timestamped directory:

```
results/
├── YYYYMMDD_HHMMSS/
│   ├── consolidated_results.json      # Machine-readable results
│   ├── BENCHMARK_REPORT.md            # Human-readable summary
│   ├── python_comprehensive_output.txt
│   ├── milestone_benchmark_output.txt
│   ├── rust_criterion_output.txt
│   └── rust_comprehensive_example_output.txt
├── YYYYMMDD_HHMMSS/
│   └── ...

```

## Running Benchmarks

**Run all benchmarks** (comprehensive):
```bash
python3 run_all_benchmarks.py
```

**Quick mode** (~5 minutes):
```bash
python3 run_all_benchmarks.py --quick
```

## Troubleshooting

**Python benchmarks fail**:
- Check dependencies: `pip install -r requirements.txt` (if exists)
- Verify Python path: `python3 --version` (should be 3.9+)

**Rust benchmarks fail**:
- Rebuild first: `cd hcvlang && cargo build --release`
- Check Rust version: `rustc --version` (should be 1.70+)
- Known issue: FFI benchmarks may fail if symbols not exported

**Timeout errors**:
- Use `--quick` mode for faster runs
- Increase timeout in `run_all_benchmarks.py` if needed
