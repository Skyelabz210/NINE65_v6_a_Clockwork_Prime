# 12_EXPORTS - Formatted Outputs

This folder contains formatted exports of QMNF System documentation for distribution.

## Contents

### pdf/
PDF versions of documentation.
- Master guides
- Technical reports
- Formal papers

### docx/
Word document versions.
- Editable guides
- Review documents
- Collaboration drafts

### presentations/
Slide decks and presentations.
- Technical presentations
- Overview slides
- Training materials

## Export Workflow

1. **Source**: Markdown in daily_planet folders
2. **Convert**: Using pandoc or similar tools
3. **Output**: Formatted versions in this folder

## Naming Conventions

```
DOCUMENT_NAME_YYYY-MM-DD.ext
```

Examples:
- `SYSTEM_GUIDE_2025-12-16.pdf`
- `DEVELOPER_REFERENCE_2025-12-16.docx`
- `QMNF_OVERVIEW_2025-12-16.pptx`

## Quality Notes

- PDFs should include clickable links
- DOCX should preserve formatting
- Presentations should embed diagrams
