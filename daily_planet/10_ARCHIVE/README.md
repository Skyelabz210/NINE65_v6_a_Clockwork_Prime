# 10_ARCHIVE - Historical Content

### canonical_versions/
Point-in-time snapshots of documentation state.
- `v1.0_december_2025/` - Initial organized release

### deprecated_docs/
Old documents that may still be referenced.
- Superseded designs
- Old API documentation
- Historical decisions

### session_archive/
Older session reports (pre-organization).
- Early development sessions
- Historical progress

### benchmark_archive/
Historical benchmark results.
- Old performance data
- Superseded measurements
- Trend analysis data

## Archive Policy

Files are moved here when:
1. **Superseded**: A newer version exists
2. **Deprecated**: No longer accurate but referenced
3. **Historical**: Valuable for context only
4. **Old sessions**: Beyond active reference period
