# Plan: FHE Microservice — Isolate Python Bindings

## Context

`nine65-python` (pyo3 0.28 cdylib) has 81+ compilation errors that break `cargo check --workspace`. Rather than chasing pyo3 API churn, we restructure the Python integration as a microservice: the Rust FHE engine runs as an HTTP service, and Python talks to it via a thin SDK client. This isolates external binding dependencies from the core workspace permanently.

## Architecture

```
Core Workspace (always green)          External Clients
┌──────────────────────────────┐       ┌─────────────────┐
│ nine65, clockwork-core,      │       │ sdks/python/     │
│ nexgen_rational, mana, unhal │       │   nine65_sdk/    │
│ exact_transcendentals        │       │   (pure HTTP)    │
│ fhe-service (HTTP boundary)  │◄──────┤                  │
└──────────────────────────────┘       └─────────────────┘

Excluded (standalone builds):
  crates/nine65-python/  (pyo3)
  crates/nine65-wasm/    (wasm-bindgen)
```

## HVTs (High-Value Targets) — Include Now

### HVT-1: TrackedEvaluator for automatic noise budget tracking
- **Location:** `crates/nine65/src/ops/homomorphic.rs` (line 292+)
- **What:** Wraps `BFVEvaluator`, intercepts every op, tracks noise budget in millibits
- **Effort:** Trivial — use it as session evaluator instead of raw BFVEvaluator
- **Value:** High — sessions auto-track noise, can reject ops when budget exhausted
- **Impact on plan:** Session model gains `noise_budget_millibits` field; evaluate endpoint returns current budget

### HVT-2: GSO-FHE depth-50 operations
- **Location:** `crates/nine65/src/ops/gso_fhe.rs` (1017 lines, fully implemented + tested)
- **What:** `GSOFHEContext` wraps ciphertexts with `GSOCiphertext`, provides `mul_symmetric()`/`mul_public()` with automatic basin collapse for unlimited depth
- **Effort:** Small — add `gso_mul` operation type to evaluate endpoint
- **Value:** High — this IS the nine65 differentiator (depth-50 without bootstrapping)
- **Impact on plan:** New evaluate op `gso_mul`; session optionally wraps in GSO context

### HVT-3: Test infrastructure reuse
- **Location:** `crates/nine65/src/params/secure_configs.rs` (test_fast), `params/mod.rs` (for_depth)
- **What:** `SecureConfig::test_fast()`, `FHEConfig::light()`, `ShadowHarvester::with_seed(42)`
- **Effort:** Trivial — import in fhe-service tests
- **Value:** Medium — reproducible, fast tests without writing setup boilerplate
- **Impact on plan:** fhe-service tests use `allow_insecure` feature for fast test configs

### HVT-4: HTTP hardening (body size + connection limits)
- **Location:** `crates/fhe-service/src/main.rs` lines 155-161 (body read), 98-110 (thread spawn)
- **What:** Enforce max body size before reading; cap concurrent connections
- **Effort:** Trivial — ~10 lines each
- **Value:** High — prevents trivial DoS on the service
- **Impact on plan:** Add constants `MAX_BODY_BYTES` and `MAX_CONNECTIONS`; check in http.rs and main.rs

## Step 3: Refactor fhe-service into Modules

Extract the existing 502-line `main.rs` monolith into:

```
crates/fhe-service/src/
  main.rs          # Entry point: listener, connection limit, routing dispatch
  http.rs          # HttpRequest/HttpResponse parsing (extracted verbatim + body size limit)
  session.rs       # Session struct + SessionStore (RwLock<HashMap>)
  wire.rs          # Serde request/response types for JSON bodies
  handlers.rs      # All endpoint handlers (health, sessions, encrypt, evaluate)
```

### Session Model

```rust
struct Session {
    session_id: String,          // "sess_<32-hex-chars>" via getrandom
    config_name: String,         // "secure_128" | "secure_192" | "secure_256"
    config: FHEConfig,
    ntt: NTTEngine,              // Send+Sync
    encoder: BFVEncoder,
    secret_key: SecretKey,       // ZeroizeOnDrop — NEVER leaves server
    public_key: PublicKey,
    eval_key: EvaluationKey,
    noise_budget: NoiseBudget,   // HVT-1: auto-tracked in millibits
    operation_count: u64,
    created_at: u64,             // unix seconds
}

struct SessionStore {
    sessions: RwLock<HashMap<String, Session>>,
    max_sessions: usize,         // default 64, env FHE_MAX_SESSIONS
}
```

### REST API

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/healthz` | Health check (existing, add active_sessions count) |
| GET | `/v1/version` | Version + supported configs (existing) |
| GET | `/v1/metrics` | Prometheus metrics (existing, add session metrics) |
| POST | `/v1/sessions` | Create session (keygen), returns session_id + params |
| GET | `/v1/sessions/{id}` | Session info (noise budget, op count) |
| DELETE | `/v1/sessions/{id}` | Destroy session (zeroize keys) |
| POST | `/v1/sessions/{id}/encrypt` | Encrypt value(s) → ciphertext(s) |
| POST | `/v1/sessions/{id}/decrypt` | Decrypt ciphertext(s) → value(s) |
| POST | `/v1/sessions/{id}/evaluate` | Homomorphic ops (add, sub, mul, gso_mul, etc.) |

### Wire Format

Ciphertexts travel as **bincode → base64** strings in JSON. Deserialized via `Ciphertext::from_bytes_validated(bytes, n, q)` which validates degree, modulus, and coefficient bounds.

### Evaluate Operations

```json
POST /v1/sessions/{id}/evaluate
{
  "operations": [
    { "op": "add", "inputs": ["<ct_b64>", "<ct_b64>"] },
    { "op": "sub", "inputs": ["<ct_b64>", "<ct_b64>"] },
    { "op": "negate", "inputs": ["<ct_b64>"] },
    { "op": "add_plain", "inputs": ["<ct_b64>"], "scalar": 10 },
    { "op": "mul_plain", "inputs": ["<ct_b64>"], "scalar": 3 },
    { "op": "mul", "inputs": ["<ct_b64>", "<ct_b64>"] },
    { "op": "gso_mul", "inputs": ["<ct_b64>", "<ct_b64>"] }
  ]
}
```

Response includes `noise_budget_millibits` after all operations.

## Step 4: Python SDK

**Location:** `sdks/python/nine65_sdk/`

Pure-Python HTTP client. No Rust dependencies. Depends only on `requests`.

```
sdks/python/
  pyproject.toml
  nine65_sdk/
    __init__.py
    client.py        # FHEClient: create_session, health, version
    session.py       # Session: encrypt, decrypt, add, mul, gso_mul, context manager
    ciphertext.py    # Ciphertext: opaque b64 wrapper
    errors.py        # Nine65SDKError, SessionNotFoundError, NoiseBudgetExhaustedError
  tests/
    test_roundtrip.py  # Integration test vs running service
```

### Usage

```python
from nine65_sdk import FHEClient

client = FHEClient("http://localhost:8080")
with client.create_session("secure_128") as session:
    ct_a, ct_b = session.encrypt(42, 17)
    ct_sum = session.add(ct_a, ct_b)
    result = session.decrypt(ct_sum)
    print(result)  # [59]
    print(session.noise_budget_millibits)
```
