### Failure Mode 1: No Peak at Depth 21-23

- k parameter not optimal (try range 30-70)
- Modulus too small (need >10^6)
- Initial conditions not diverse enough
- History window too short (<100)

### Failure Mode 2: No Noise Enhancement
**Possible Causes:**
- Phase calculation incorrect (verify mod 2π)
- Noise magnitude too large/small (optimal 10-20%)

### Failure Mode 3: No φ-Resonance

- Comparison ratios not spread enough
- Convergence measure inappropriate
- Need more trials (>50 per ratio)

### Failure Mode 4: Poor Regeneration
