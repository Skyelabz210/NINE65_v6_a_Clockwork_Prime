## SECTION D: INTEGER-ONLY SCORING SYSTEM

### D1: Turnkey Scoring (Ready-to-Retail)

```
TURNKEY SCORE = (3 × MARGIN) + (2 × DEMAND) + TURN - (2 × RISK) - FRICTION

Where (all integers 0-1000):

MARGIN = price_vs_comp_delta_basis_points / 10
  - If asking 10% below comp median → MARGIN = 1000
  - If asking at comp median → MARGIN = 500
  - If asking 10% above → MARGIN = 0

DEMAND = model_heat_index
  - GT3/Pista/SVJ: 950-1000
  - Standard 911/Huracán: 700-850
  - Older McLaren: 500-650

TURN = expected_days_to_sale_inverse
  - <30 days expected: 1000
  - 30-60 days: 750
  - 60-90 days: 500
  - >90 days: 250

RISK = title_risk + condition_risk + seller_risk
  - Clean title, excellent: 0-200
  - Minor issues: 200-500
  - Significant concerns: 500-800
  - Major red flags: 800-1000

FRICTION = acquisition_difficulty
  - Local private seller: 100
  - Regional dealer trade: 300
  - Auction requiring transport: 500
  - Out-of-state complex: 700-900
```

**Turnkey Thresholds:**
- **≥ 2000**: IMMEDIATE BUY (call within 1 hour)
- **1500-1999**: STRONG OPPORTUNITY (same-day outreach)
- **1000-1499**: MONITOR (add to watchlist)
- **< 1000**: PASS

### D2: Build-Ready Scoring (Project Cars / Shells)

```
BUILD SCORE = (4 × MARGIN_POTENTIAL) + (2 × PARTS_AVAILABILITY) + PLATFORM - (3 × COMPLEXITY) - RISK

Where (all integers 0-1000):

MARGIN_POTENTIAL = (estimated_built_value - acquisition - build_cost) / estimated_built_value × 1000
  - 50%+ margin potential: 900-1000
  - 30-50%: 700-900
  - 15-30%: 400-700
  - <15%: 0-400

PARTS_AVAILABILITY = how easy to source components
  - Ferrari 360/F430: 850 (abundant)
  - Gallardo: 900 (very common)
  - McLaren MP4-12C: 600 (improving)
  - Carrera GT: 300 (rare, expensive)

PLATFORM = build community + resale demand for builds
  - GT-R (R35): 950 (proven platform)
  - Huracán: 850 (twin-turbo scene)
  - 996/997: 900 (Singer-style demand)
  - Ferrari 458+: 700 (newer, less modified)

COMPLEXITY = build difficulty estimate
  - Mechanical only (engine swap): 300
  - Mechanical + electrical: 500
  - Fire/flood (full rewire): 700
  - Structural damage: 850
  - Frame damage: 950

RISK = title + legal + hidden damage risk
  - Salvage rebuildable (inspectable): 300
  - COD waiver state: 500
  - Unknown damage extent: 700
  - Potential frame issues: 900
```

**Build-Ready Thresholds:**
- **≥ 2500**: ACQUIRE NOW (rare margin opportunity)
- **1800-2499**: STRONG BUILD CANDIDATE (inspect + negotiate)
- **1200-1799**: WATCHLIST (right price could work)
- **< 1200**: PASS (margin doesn't justify complexity)
