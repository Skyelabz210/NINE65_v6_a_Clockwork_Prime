# BUILD-READY SHELL PIPELINE — Quick Reference
## Not Junk Cars. Rebuildable Exotics.

**Philosophy:** You can't have a "junk car" of a supercar. These are damaged assets with intact value cores — frames, monocoques, drivetrains — that become high-margin retail units with the right build partner.

---

| Acquisition | + Build Cost | = Total In | vs. Retail | = MARGIN |
|-------------|--------------|------------|------------|----------|
| $50K shell | $40K rebuild | $90K | $180K | **50%** |

## WHAT TO BUY (Shell Selection Criteria)

### ✅ BUY THESE DAMAGE TYPES

| Damage | Why Good | Risk Level |
|--------|----------|------------|
| **Rear collision** | Engine/trans forward (mid-engine), shell intact | LOW |
| **Rear fire** | Same — fire starts rear, front clean | LOW-MEDIUM |
| **Mechanical failure** | Drivetrain out, body perfect | LOW |
| **Electrical only** | Harness replacement, body intact | MEDIUM |
| **Light flood (interior)** | Carpet/seats, mechanicals often OK | MEDIUM |

### ⚠️ PROCEED WITH CAUTION

| Damage | Why Risky | When OK |
|--------|-----------|---------|
| **Front collision** | May affect monocoque/frame | Only if explicitly inspected |
| **Deep flood** | ECUs, sensors, wiring all compromised | Only if priced at shell value |
| **Side impact** | B-pillar, door structure, possible frame | Rare to be worthwhile |

### ❌ AVOID

| Damage | Why |
|--------|-----|
| **Frame damage** | Structural integrity compromised |
| **Monocoque crack** | Carbon tubs are totaled if cracked |
| **Theft recovery (stripped)** | Parts cost exceeds value |
| **Certificate of Destruction** | Cannot be titled in most states |

## BUILD PIPELINE WORKFLOW

```
1. SCOUT
   └─► Search salvage auctions daily
   └─► Set alerts on broker sites
   └─► Monitor forum classifieds

2. EVALUATE
   └─► Check damage photos carefully
   └─► Verify title type (Salvage vs COD)
   └─► Estimate repair scope
   └─► Calculate margin

3. ACQUIRE
   └─► Set max bid (acquisition + build < 60% of retail)
   └─► Arrange transport
   └─► Verify condition on arrival

4. BUILD
   └─► Document everything (before/after)
   └─► Use certified parts where needed
   └─► Track all costs

5. CERTIFY
   └─► State inspection for rebuilt title
   └─► Full documentation package
   └─► Transparent disclosure

6. RETAIL
   └─► Price at rebuilt market (typically 70-80% of clean)
   └─► Marketing emphasizes quality of build
   └─► Build story = selling point
```
