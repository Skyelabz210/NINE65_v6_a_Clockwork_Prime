### Fix 1: IsUnit Coprimality Proof (Lines 115-135)

**Problem:** Original code used `ZMod.isUnit_prime_iff_not_dvd` which requires β_cap to be prime.

**Solution:** Use `ZMod.isUnit_iff_coprime` which works for any coprime pair.

```lean
have h_inv : IsUnit (cfg.α_cap : ZMod cfg.β_cap) := by
  rw [ZMod.isUnit_iff_coprime]
  simp only [ZMod.val_natCast]
  exact Nat.Coprime.coprime_mod_left cfg.coprime
```

**Mathematical Basis:** `gcd(a, n) = 1 ⟺ a is a unit in ℤ/nℤ`

### Fix 2: Algebraic k Recovery (Calc Chain)

calc (((V : ZMod cfg.β_cap) - (V % cfg.α_cap : ZMod cfg.β_cap)) *

    = (V / cfg.α_cap : ZMod cfg.β_cap) * (cfg.α_cap : ZMod cfg.β_cap) *
      (cfg.α_cap : ZMod cfg.β_cap)⁻¹ := by rw [h3]

      rw [IsUnit.mul_inv_cancel h_inv, mul_one]
